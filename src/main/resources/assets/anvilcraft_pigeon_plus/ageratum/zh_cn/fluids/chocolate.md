# 熔融巧克力

<item id="anvilcraft_pigeon_plus:liquid_chocolate_bucket"/>

熔融巧克力是巧克力的熔融态，分为普通、黑、白三种，各自对应本体的巧克力块。

## 熔炼

在大型炼药锅下方放置加热器，把巧克力块加热即可熔融成对应的熔融巧克力，每块产出 **1000 mB**。

| 输入 | 产出 |
| --- | --- |
| 巧克力块 | 熔融巧克力 1000 mB |
| 黑巧克力块 | 熔融黑巧克力 1000 mB |
| 白巧克力块 | 熔融白巧克力 1000 mB |

## 搅拌合成

也可以跳过合成巧克力块的步骤，直接把原料放进炼药锅搅拌。

- 熔融巧克力：可可液块 ×8 + 可可脂 ×4 + 奶油 ×4 + 糖 ×2
- 熔融黑巧克力：可可液块 ×12 + 可可脂 ×4 + 糖 ×2
- 熔融白巧克力：可可脂 ×12 + 奶油 ×4 + 糖 ×2

每份产出 **1000 mB**。

::: warning 需要加热
这些配方都要求加热：气动搅拌机必须装烈焰搅拌头，电搅拌机通电即可。详见[气动搅拌机](../devices/blender)与[电搅拌机](../devices/electric_blender)。
:::

## 冷凝

熔融巧克力在炼药锅中静置冷凝，可以还原成对应的巧克力块，**1000 mB** 产出 **1 个**巧克力块。

## 灌注饼干柱

手持熔融巧克力桶右键曲奇柱，可以直接把曲奇柱灌成巧克力夹心饼干柱，详见[巧克力夹心饼干柱](../devices/chocolate_cookie_pillar)。
